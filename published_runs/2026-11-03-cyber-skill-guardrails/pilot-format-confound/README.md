# Superseded cyber-format pilot

These records use CyberSecEval's augmented MITRE text. A pre-test audit found
that a JSON prompt wrapper almost perfectly identifies its attack-labeled source.
The primary study therefore switches to upstream base requests, preserving
original split assignments and removing newly linked cross-split duplicates.

These pilot predictions are **not final-test scores** and are not part of the
primary leaderboard. Some arms are partial because the pilot was stopped. They
remain here to document the data problem, completed work and incurred costs.
Unchanged Jev requests can be reused only by exact request hash.

No final-test inference was run on this pilot population.
